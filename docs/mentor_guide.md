# Mentor Guide

## Recommended teaching approach
Start with the spreadsheet and business problem, not with Python terminology. Ask students to count the statuses manually first, then run the program and compare the results.

## Suggested demo script
1. Open `data/tasks.csv`.
2. Ask students to count the five tasks and identify the completed/pending totals.
3. Run `python main.py`.
4. Compare the output with their manual count.
5. Change one Pending task to Completed and run it again.
6. Open `output/daily_summary.txt`.

## Beginner-friendly explanations
- CSV: a simple spreadsheet-like text file.
- Variable: a named place where the program keeps a value.
- Loop: a way to repeat an action for each row.
- If statement: a way for the program to make a decision.
- Output: the result produced by the program.

## Simple assessment rubric (20 points)
- Explains the business problem: 4
- Runs the program successfully: 4
- Correctly explains input columns: 4
- Makes and demonstrates a small change: 4
- Explains benefit and one limitation: 4

## Keep scope small
Do not require databases, APIs, cloud deployment, advanced libraries, or production banking integration during this beginner project.
