# Four-Week Internship Plan: Daily Operations Task Tracker

## Week 1 — Understand the problem and set up Python
**Explain:** Operations teams use spreadsheets to track work. Counting task statuses manually takes time.

**Activities**
- Open `data/tasks.csv` in Excel.
- Identify each column and what one row represents.
- Install Python and configure the editor.
- Run `python main.py` and read the output.

**Deliverables**
- A one-page setup guide: tools installed and how to run the program.
- A short explanation of the business problem.

**Reflection**
1. What does each row in the spreadsheet represent?
2. Why might counting tasks manually be repetitive?
3. What did I install to run the program?

## Week 2 — Understand the data
**Activities**
- Add three new fictional tasks to the CSV.
- Change statuses between Pending and Completed.
- Run the program after each change.
- Learn what a row, column, text value, and CSV file mean.

**Deliverables**
- Updated sample task file.
- A simple data map explaining Task ID, Task Name, Assigned To, and Status.

**Reflection**
1. Which column determines whether a task is completed?
2. What happens when I add a new row?
3. Why should task statuses use consistent words?

## Week 3 — Improve the automation
**Activities**
- Read the simple Python script line by line with the mentor.
- Change the program to also count tasks assigned to each person, or add a third status such as On Hold.
- Test what happens if the input file is missing.
- Compare the program's result with a manual count.

**Deliverables**
- An improved working script.
- Two or three test examples showing the expected and actual results.

**Reflection**
1. Which part of the script reads the spreadsheet?
2. Which part counts completed tasks?
3. What did I do to check that the results were correct?

## Week 4 — Demonstrate the project
**Activities**
- Prepare a short demo using fictional tasks.
- Show the input file, run the script, and open the generated summary.
- Explain the benefit to a non-technical audience.
- Suggest one future improvement.

**Deliverables**
- A 3–5 minute demonstration.
- A 3–5 slide presentation.
- A short reflection on what was learned.

**Reflection**
1. What repetitive task does my program automate?
2. How did I verify the counts?
3. What would I improve if I had another week?
4. How could this help an operations team?
5. What did I learn about automation?
